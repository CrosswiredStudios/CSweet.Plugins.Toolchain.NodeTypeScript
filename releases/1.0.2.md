# 1.0.2

Validate the Office's actual Node and npm versions before executing a recipe, and report observed runtime and installed package versions in provenance. Failed environment checks retain their observed evidence.

Certification captures wait for a rendered frame and use fixed browser settings with deterministic PNG evidence instead of timestamped video output. Requires a Node 24.15.0 / npm 11.12.1 Office image containing the exact fixture dependency cache and Playwright 1.62.1 Chromium (Office 0.14.0 image preparation). Re-certify this published provider against that image before project selection. The four build permissions and no-network policy are unchanged.
